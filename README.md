# Quest Play
Progetto sviluppato in Unity per Meta Quest, che mira a ricreare l'esperienza di 5 minigiochi di Wii Play adattandoli alla realtà virtuale.

### Specifiche Tecniche
- Engine: Unity
- Target Device: Meta Quest platform (XR Interaction Toolkit), principalmente Quest 2, testato e funzionante anche su Quest 3.

## Stato del progetto
| Minigioco | Stato | Note |
| :--- | :--- | :--- |
| **Menù Principale** | Finito | Menu dei giochi, con leaderboard, follow dello sguardo e altezza dinamica. |
| **Charge** | Finito | Guida una mucca, abbatti gli spaventapasseri, vai veloce. |
| **Ping Pong** | Finito | Ping Pong, rispondere all'infinito a battute |
| **Shooting Range** | Finito | Sparare a palloncini, lattine e bersagli |
